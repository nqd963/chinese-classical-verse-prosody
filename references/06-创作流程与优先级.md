# 创作方法论：决策链与两套优先级

> 本文件是**创作指导，不是机器判定规则**。凡标「不可机检」的条目不得写成断言，也不得作为 `fail` 依据。
> 依据：工作区 21 份深读报告 + 四轮外部研究（原文与 URL 见 `00-资料勘察/`，本文件只留可执行动作）。

## 一、两套优先级（最容易搞错的一件事）

常见写法把「平仄 > 押韵 > 对仗 > 语言 > 意境」当顺序——那是**校验优先级**，不是创作优先级。

- **创作**：意境第一（人间词话 19）、诗心为本（顾随 3676）、别材别趣（沧浪 35）——先想表达什么，再找容器
- **校验**：平仄 → 押韵 → 粘对 → 对仗字数 → 意境层只提示不对错

把校验顺序当创作顺序，产出的是闻一多所讥的「精密的类书」——声律齐整而无诗。

## 二、为什么是决策链，不是工序表

旧版八步（定体→立意→…→机检）是「先定形式→填内容→最后打磨」的**工序表**。
十二首名作反推显示：写作是**每个节点面对一组可选方案、诗人做了选择**的**决策树**。
二者差别在：工序表只有「写什么」的加法，决策链还包含「不写什么」的减法。

**读法**：每层标「输入 / 决策 / 输出 / 可机检 / 不可机检」。机器只做能做的，其余交人。

## 三、七层决策链

### L0 感动与立意【不可机检】

- **输入**：生活感触
- **决策**：真有感动吗？一句话说清「要说什么」；遮题测试——换题仍成立即空泛（蕙风 205）
- **输出**：立意句 + **情绪标签**（悲/喜/沉雄激壮/掩抑凄凉/哀艳缠绵/清空萧洒）
- 依据：叶嘉莹「感发生命」、顾随「诗心」

### L1 择体与定眼【部分可机检】

- **输入**：立意句 + 情绪标签
- **决策**：情绪配体（不是先选体再塞情绪）；炼字**第一次介入**——定「眼」的类型：集义明理/赋形写意/造势
- **输出**：体式（近体四体或词牌）、定格/又一体、眼的类型
- 可机检：`check.py cipai` 查体式与 `evidence_level`
- **不可机检**：词的声情与词情是否相应（龙榆生：只按字数套谱＝长短句之律诗）

### L2 择境取象【不可机检，四段十二步】

- **输入**：立意 + 情绪
- **决策链**（详见 `深读-意象组织机制.md`）：

| 段 | 步骤 | 关键判据 |
|---|---|---|
| 选 | 定情感方向→定兴/比→**避熟就生**（取材层，不只修辞）→切至与写精神 | 「老杜不但修辞避熟就生，其取材亦出奇」（顾随 1758）；「比类虽繁，以切至为贵」（文心 173） |
| 组 | 选组合方式→**诸象共载一意**→调疏密 | 组合后彼此冲突/削弱即无美学价值；「密在字面，厚在意味……密而能疏宕，始能真厚」（蕙风 2221） |
| 推 | 逐层迤逦入胜→转折至少到「意圆」→忌百首如一首 | 笔圆（恃虚字）/意圆（前后呼应）/神圆（潜气内转）三层（蕙风 69/2107） |
| 收 | 选煞尾或度尾→以景结情四检 | 是景？暗合情绪或带象征？清音有余？收束完密不伪留白 |

**最短四问**：是我的此刻还是古人的影子？是否共指一意？是否逐层变化？结句之景是否暗合前文且留余味？

**重要修正**：不存在「月＝悲」的固定对应。王夫之「以乐景写哀，以哀景写乐，一倍增其哀乐」——
情景可同向可反向，取决于物我关系、语境与传统象征。前轮「意象三重性」的人文符号层**不可当固定查表**。

### L3 章法：起承转结四个独立决策【部分可机检】

- **起**：单起/对起、兴起/赋起、切题/造势。忌泛入闲事、忌起句坐实太满
- **承**：铺景/铺情、递进/并列；洁—力交替；承联末三字为转铺垫
- **转**：三分法——进一层 / 推开一层 / 反转；**形转而意不转**（换景换事可以，主题不能换）
- **结**：以景结情 / 宕开 / 拍合 / 问句 / **以缺席收** / 反跌

**改稿顺序与创作反向**：结句 → 发句 → 对句（沧浪诗法）。

### L4 定韵【可机检】

- **决策**：韵部、平仄、是否邻韵（严格模式默认关闭邻韵）
- 可机检：`check.py char` 查字韵部与多读；出韵、重韵、邻韵模式全可硬判
- 注意：入声字、多读字是最大风险点（「客」入声、「梦」两读）

### L5 炼字钉死【部分可机检】

炼字**第二次介入**（第一次在 L1 定眼）：

- 一诗之眼：抽掉哪句全篇失色？
- 炼字七检（一字师七例）：数量词试删/抽象字换含蓄/反问递进互换/情感取向核对/感官动词替换/同句偏旁检查/全首重字
- **曲喻判据**（钱锺书）：全体相似则无需比拟；一端相似推及他端才是曲喻
- 改字双检（夏承焘）：先查声调，再查意象色彩
- 可机检：字数、重字、平仄｜不可机检：改字是否保意味

### L6 机检 + 减法决策【可机检 + 人工】

- 跑 `check.py poem/ci`、`yijing.py scan`；硬错必改，soft 斟酌，unable 存疑不改
- **减法三问**（本轮新增，此前全是加法）：哪句可删？说破了吗？留余地了吗？
- 合律 ≠ 好诗——见「已知边界」

## 四、三道贯穿层（横向，不占独立节点）

1. **尺度设计**：大千世界→六合四维→山川大地→庭园建筑→器物微物→感官/心绪。
   名作常沿阶梯缩放（极大→极小→接回时代）；小令与长调的缩放次数差异大
2. **视角设计**：我/物/你三层切换；**对写**——不说我想你，写你如何盼我；含尺度跳接与主客翻转
3. **减法决策**：以缺席收（「阳关无故人」「春风不度」）、说破即删、关节处留余地

## 五、题材路径：八类常走的路线（不是新模具）

送别 / 怀古 / 咏物 / 闺怨 / 边塞 / 山水田园 / 咏怀言志 / 节序即时，
每类的起句、承转、意象族、结句、名作例证、常见败笔见 `深读-题材章法矩阵.md`。

**用法限定**：只做「这类题材常走哪条路」的**路径标记** + 常见败笔的**反向清单**，
不做通过/不通过判定。每条套路旁须配反例——詹安泰「无一成不变之意格」、吴梅「无一定不易之文」、
缪钺「神明变化视乎作者」。矩阵是**扩宽写法选择，不是收窄成新八股**。

## 六、两条硬边界

- **对仗三层**：L1 字数平仄硬判；L2 句法 `not_supported`；L3 出处词典软证据（工对/邻对/宽对/借对/合掌/unable）带覆盖率。不得说「对仗已通过」
- **意境只提示不出对错**；未检出风险 ≠ 意境合格

## 七、可学与天才

十二首名作反推标出 13 处【天才】、14 处【反推】。以下**只可意会，不伪装成操作**：
「惘然」「一江春水」一词降全篇温度的眼；「十四字含八意」仍一气贯串的密度；
「阔从垂来」的字间发力；豪情顶点化开的分寸；「更尽」歧义够味而非含混；用典脱胎而非临摹。

**套公式能写出合律的作品，写不出这些。**

## 八、词作流程的差异

词的格律来自词谱而非近体骨架：

1. 定词牌 + 定体 → `check.py cipai 词牌名` 看体式与 `evidence_level`
2. `skeleton_only` 只有字数/句数/韵式/韵位，**不可当平仄谱**；`conflict`（退出码 3）须换词牌或人工裁定，不猜
3. 衬字、叠句、换韵按词谱核；本包 `（句）`/`（读）` 实测 0 处，**不得据标点猜句读**
4. 词味负面清单与起结过片见 `references/02-词律与词谱.md` 第九节
