# 词律与词谱（实现口径）

词的判定依据是**谱**，不是「诗律套用」。本文说明本技能怎么读谱、怎么对谱、什么时候拒绝判。

## 一、谱式数据从哪来

| 源 | 用途 | 性质 |
|---|---|---|
| 龙榆生《唐宋词格律》 | **唯一**机器判定依据（A 源） | 谱式属格律事实；书已公版，且未收其论述文字 |
| 王力《诗词格律》附録白香谱 | 仅作 A/B 交叉核对与冲突判定（B 源） | 谱式源自清·舒梦兰《白香词谱》（公版）；只取符号谱，不取论述 |

两源各有体例：A 源用 `平/中/仄` 与 `（韵）（句）〖〗『』ˇ`；B 源用 `－｜＋＝＄‖`。**必须先归一再比对**，直接拿符号比出来的差异一律无效。

## 二、谱行的结构

一条谱行（`cipu_long.json` 的 `lines[i]`）包含：

- `pat` —— 等长谱串：`P` 定平、`Z` 定仄、`*` 可平可仄；
- `rhyme` —— 等长 0/1 掩码，1 表示该位是韵脚；
- `opt` —— 衬字插入点（`pat` 下标，表示「插在该下标之前」）；
- `punct` —— 行末标点；`pian` —— 第几片；
- `raw` —— 原文谱行，供人工复核；`raw_ref` —— 行号。

**谱行内部也可能有「，」**（如忆江南首行「平中仄，中仄ˇ仄平平（韵）。」）。因此对谱时必须先算「该谱行由几个子句、各几字组成」（`ci._raw_seg_lens`），再逐段消费用户断句。直接按「一行＝一句」对，会在含逗号的谱行上整体错位。

## 三、衬字位（`ˇ`）

龙榆生谱里的 `ˇ` 是**衬字标记**（原书图例：「ˇ 表可用衬字处」），该位 **0 字或 1 字皆合法**。全谱 5 处，分布在忆江南 1 处、行香子 3 处、御街行 1 处。

- 实现：`opt` 槽，按「删/留」两种长度展开成候选谱串，取平仄吻合最多者；
- 用了衬字时报 `V-OPT`，**severity = soft**（备忘，不是错误）；
- 反例警示：《白香词谱》抓取本里的 `ˇ`（1089 处）是**字符丢失**，与龙榆生的衬字标记同形异义，该文本整体禁用，不得共用一条规则。

## 四、词的句读

源数据实测：`（韵）` 1797 处，`（句）` 0 处，`（读）` 0 处。故**句读只能由行尾标点确定**，不得假设有句读标记。

用户输入同样按标点断句（`。！？，、；：`），与谱行子句逐段对齐；段数对不上即 `V-CHARS`，不擅自重排句序。

## 五、用韵：词韵与诗韵不同书

词用《词林正韵》19 部（14 平上去 + 5 入声），**不用平水韵 106 韵目**。混用会得出系统性错误结论。

- 韵脚判定：同一部即合韵；谱上标了换韵/增韵处，允许另起一部；
- 谱未标换韵而韵部变了 → `V-RHYME-SHIFT`；
- 同字复用为韵脚 → `V-RHYME-DUP`（soft，叠句除外）；
- 叠句/叠三字：谱上有 `〖` 标记处，须与上句相同，或末三字相同，否则 `V-REPEAT`。

## 六、三口径与体式头

词牌数量有三套互不通用的口径，引用时必须写明是哪一套：

- **208 标题数** = 145 词牌头 + 63 体式头（`##` 级）
- **201 体式** = 138 定格 + 63 变体
- **155 词牌去重正名**（裁决书写 156，实测 155，差 1 待稽）

另：`###` 级 138 个【定格】头不计入 208；level 0 的 10 个词牌头也不计入。

体式头有两种统计口径（架构师 63 / 构思方 54）。实测可复现的三种规则分别得 63 / 58 / 53；**54 无法由任何单一显式规则复现**，差集已在 `cipai_index.json.summary.体式头双口径` 中逐条列出，等待统一口径。

## 七、等级早退：二等不作机器判定

双源冲突且未经人工裁定的词牌，一律降为**二等**，`check.py ci` 直接返回 `conflict`（退出码 3），只能作人工参照。

「择一为准」被明确禁止：择 A 会因宽严不一误判，择 B 覆盖面不足，取交集会误杀合规作品。承认「这条没把握」比给出一个可能错的「通过」更有价值。

配对尤其不能猜：`格二（摊破浣溪沙）` 这类带括号注的体式头，与 B 源独立条目的对应关系**必须人工裁定**并标 `decided_by`。自动配对会造出假冲突 → 触发降级 → 把本该一等的词牌伪造成二等，与「二等伪装成一等」同属诚信失守。

## 八、置信分级

- `first`（一等）：单一谱源 + 归一比对无冲突，可作机器判定；
- `second`（二等）：冲突未裁定 / 仅有人工参照，只作提示。

输出里 `confidence.level` 与 `confidence.basis` 必须能对上这张表，不允许含糊。


## 九、词味与择调（外部深读补充，来源分级标注）

> 原文与 URL 见工作区 `00-资料勘察/深读-外部-填词技巧.md`（454 行 / 49 URL）。
> 以下只列可执行动作。**这些是软提示，不进硬校验**——词的格律硬判仍按前八节。

### 9.1 择调先看情绪，再看字数（龙榆生 1937 原刊，A）

> 「私意选调填词，必视作者当时所感之情绪奚若，进而取古人所用之曲调，玩索其声情……必也曲中之声情，与吾所欲表达之词情相应，斯为得之。」
> 「若但以依『曲拍为句』，为之尽填词之能事，则亦等于作长短句之律诗耳。」

**动作**：写词前先写一句「本篇情绪标签」（悲／喜／沉雄激壮／掩抑凄凉／哀艳缠绵／清空萧洒），据此选调。
**只按字数平仄套谱 = 长短句之律诗**，即「诗味」的根源。

声情映射（龙榆生）：奇偶相生、平仄相间、隔句协韵 → 和婉；多偶或多奇句 → 倔强；
二句结尾叠用平声易凄抑、叠仄声见激厉；用韵疏密得中者和、过当者情急；
入声韵迫促愤怨、慷慨激越，去上韵沈咽悲凉。反面：《寿楼春》本凄调却被误用祝寿。

### 9.2 题中不宜于词者，直可不作（詹安泰，A-）

题材 → 命意配表：抒情宜婉曲/层深；模山范水宜空灵/高妙；咏物宜清新；
感怀宜沉挚；寄兴宜超奇/幽远；托讽宜含蓄。

### 9.3 词味负面清单（可软提示）

吴梅「上不似诗，下不类曲」；扫去：
① 诗中习见辞语照搬（须多读古人旧作得气味）；② 曲中俗字衬贴字（你我/这厢/那厢/虽则是/却原来）；
③ 说理叙事（缪钺「径狭」，苏辛说理词「读之索然无味」）；④ 感情直线、语言一口气说完；
⑤ 境太显（「词境如雾中之山，月下之花……必求明显，反伤浅露」）。

**但不可把词味简化成柔弱纤巧**——缪钺明言「其文虽小，而用意用笔固极重大；其质虽轻，而情思固极沉挚」。

### 9.4 起结过片

沈义父「起句便见所咏之意，不可泛入闲事」「结句须要放开，含有余不尽之意，以景结情最好」；
沈祥龙「有单起之调，贵突兀笼罩；有对起之调，贵从容整炼」，结六法：拍合/宕开/醒明本旨/转出别意/就眼前指点/题外借形；
过片「辞意断而仍续……前虚则后实，前实则后虚」。

### 9.5 改字双检（夏承焘实例）

改一字先查声调（入/平），再查意象色彩。例「深浅杂花吐未齐」→「闲花」：
既把入声「杂」换平声「闲」，又把芜乱景象转入幽雅境界——**一字同时校声律与意境**。
另「行幽谷」→「循林薄」理由是「诗写幽深，精华不应预先泄露，改一下就有层次了」——信息释放顺序。

### 9.6 边界（名家自划）

龙榆生「宫谱久亡，遗音莫审……其必不可知者，亦附诸『盖阙』之义可耳」——声情只能类比，不可反推；
吴梅「能与人规矩，不能使人巧也……律可合，而音不可求」；
詹安泰「有一成不变之章句，而无一成不变之意格」「袭其形貌，神弗肖也」。

**可机器化的只有**：题材排除、意象尺度、辞语来源、直说程度、首句、声情匹配、句式特征。
感情线、语言线、情感重量、境的显隐、口吻姿态**只能存疑提示，不能作通过/不通过判定**。
