# chinese-classical-verse-prosody

**古典诗词格律校验与创作辅助 Skill** —— 近体诗与词的机器校验器，附带一整套有古典文献依据的创作指导。

> 目标不是「替你写诗」，也不是「给诗打分」，而是把**能机器判定的部分判得可复核**，把**判不了的部分明说判不了**。

---

## 一、它解决什么问题

传统上问「这首诗合不合律」，答案靠人凭记忆和语感。本技能把这件事变成可复核的机器判定：

- 每条结论带 **规则编号、实测值、期望值、句字定位**
- 所有判定基于随包分发的韵表和词谱数据，**不依赖网络、不依赖大模型记忆**
- 数据缺失或双源冲突时返回 `insufficient_data` / `conflict`，**绝不猜、绝不误判成「出律」**

同时它清楚区分两件事：

| | 创作时 | 校验时 |
|---|---|---|
| 顺序 | 立意 → 择境 → 章法 → 韵与骨架 → 炼字 → 机检 | 平仄 → 押韵 → 粘对 → 对仗字数层 → 意境层只提示 |
| 原则 | 意境第一（境界为最上、诗心是根本） | 形式优先，软判据不出对错 |

把校验顺序当创作顺序，产出的是「声律齐整而无诗」——这是本技能反复强调的分界。

## 二、能力分层

### 2.1 近体诗（五绝 / 七绝 / 五律 / 七律）

硬判：

- 平仄：8 正格骨架 + 允许集合（一三五有限自由，二四六钉死）
- 粘对、孤平、拗救（对句相救须联判，报拗位与救位双坐标）
- 三仄尾**有条件合法**（五言 `平平仄仄仄`、七言 `仄仄平平仄仄仄`），只有上二/上三字不同平才是硬错；**三平尾无条件禁**
- 押韵：平水韵 + 词林正韵补全，出韵、重韵；邻韵默认关闭，仅 `--mode compat` 首句可借
- 重字、同字复用提示
- 特拗默认 soft，加 `--strict-teao` 才按严格口径报硬错
- 折腰体只认绝句，律诗单点失粘不按折腰处理

### 2.2 词

- 一等谱（龙榆生《唐宋词格律》+ 王力附録白香谱，双源交叉、冲突降级）：完整校验字数、平仄、韵位、换韵、叠句、衬字位
- 推定谱 **1884 条**：由钦定词谱例词反推，`confidence.level = provisional`，**韵脚平仄硬判、非韵脚一律 soft**
- 骨架级 `skeleton_only`：只有字数/句数/韵式/韵位，`ci` 直接拒绝，不拿骨架当平仄谱套用
- 词的四声（如某些词牌转折处必用去声）**不做机器判定**，只提示

### 2.3 对仗三层

| 层 | 内容 | 强度 |
|---|---|---|
| L1 | 字数相等、二四六平仄相对、句末平仄相对 | **硬判** |
| L2 | 句法结构 | `not_supported`（无确定性切分器） |
| L3 | 词性/义类/工拙：工对、邻对、宽对、借对、合掌、unable | **软性证据**，带出处与覆盖率 |

L3 的证据来自骈字类编 236 门、佩文韵府对语、王力《诗词格律》判据；未覆盖处标 `unable`，不猜词性。**永不输出「对仗已通过」。**

### 2.4 意境风险扫描

否定性检查，不判「合格/不合格」：

- 可检出：有出处的**陈词套语**（13 条，叶嘉莹评花间集、钱锺书等明标）、**同辞重句式合掌**、**同义异字合掌**（文心雕龙 167 明列 5 组）
- 点化识别 12 条白名单：只报「此句有原文点化评点」这一事实，**不免除套语风险、不判好坏**
- 不实现：空泛、凑韵、警策、兴比——古人判据全需语义理解；空泛的机器代理实测误伤名作 4/30，故放弃
- 输出明写：**未检出风险 ≠ 意境合格**

### 2.5 创作指导

- 八步创作流程（含遮题测试防空泛）
- 炼字七种自检动作（一字师案例：数→一、德→风、何必→何况、恨→幸、闻→看、波→中、浪→水）
- 好诗两标准（叶嘉莹：有感动 + 能传达；「不是找美的字，是找合适的字」）
- 串味判据（晏殊词句入诗被讥、寇准七绝压五绝「点金成铁」）
- 章法布局、起承转合的具体动作
- 全部标注来源等级：工作区原书（书名+行号）与外部网页（URL）**分级存放，不混用**

## 三、设计原则

1. **可复核优先**：每个数据文件带 `source`（书名、版本、sha256）与实测统计；每条判定带定位；宁可留空不硬凑
2. **边界诚实**：判不了就说判不了。名作回归 gold30 零误报是硬门槛，任何新规则误伤名作即回退
3. **区分机器判定与模型判断**：输出 JSON 里 `confidence`、`evidence_level`、`disclosure` 字段分开，措辞不得混
4. **零第三方依赖**：仅 Python 标准库；抽取脚本、校验器、工具全部可离线复跑
5. **幂等**：抽取脚本两次运行 sha256 一致

## 八、已知边界（重要）

- **判合律，不判好**：形式合规不等于作品优秀，意境与韵味须人工判断
- **对仗覆盖率有限**：L3 实测 14%–60%，未报处不代表通过也不代表不工
- **意境不判合格**：未检出风险 ≠ 意境合格
- **推定谱仅供参考**：非韵脚位由单首例词反推，原谱「可平可仄」位无法区分固定位与偶然位（约 19%），故一律 soft
- **通用词性与句法结构未做机器判定**；流水对通用识别、扇对识别均标 `unable`
- **古体诗（含乐府、歌行）不适用**；古体留扩展接口
- 词牌未收录者不做「近似比对」

## 四、一次完整的创作 + 校验流程

**创作时**（顺序不要反）：

1. 立意 → 择境 → 章法 → 韵与骨架 → 炼字 → 机检。
   先定「要表达什么」，不要先凑平仄——详见 `references/06-创作流程与优先级.md`。
2. 定韵时查关键字：`check.py char 字 --book pingshui`，特别核入声字。
3. 近体按 8 正格骨架布句；词先查 `check.py cipai 词牌名`，确认体式与 `evidence_level`。
4. 成稿后跑 `check.py poem` 或 `check.py ci`。
5. 再跑 `yijing.py scan` 看有没有套语/合掌风险。
6. 最后按 `references/09-创作经验与名作写法.md` 做炼字七检与「换漂亮字测试」。

**校验时**（顺序不同）：平仄 → 押韵 → 粘对 → 对仗字数层 → 意境层只提示不对错。

## 五、看懂输出：三个真实例子

### 例 1：合律，返回 pass

```
python scripts/check.py poem --form wujue --text "白日依山尽，黄河入海流。欲穷千里目，更上一层楼。"
→ verdict: pass, ok: true, EXIT=0
```

### 例 2：语义被破坏但仍合律（重要）

```
python scripts/check.py poem --form wujue --text "白日依山去，黄河入海流。欲穷千里目，更上两层楼。"
→ verdict: pass, EXIT=0
```

把「依山尽」改成「依山去」、「一层」改成「两层」，读起来不通，但
「去/更/上/两」各自仍落在允许的平仄位上，所以**机器判 pass 是正确的**。

这说明本技能的边界：**它判合律，不判好**。意境、语义、韵味要自己按
`references/07` 和 `references/09` 自检，或跑 `yijing.py scan`。

### 例 3：真正的硬错

```
python scripts/check.py poem --form wujue --text "白日依山明，黄河入海流。欲穷千里目，更上一层楼。"
→ verdict: violations, hard=2, EXIT=1
   (1,3) 三平尾（近体大忌） 平 -> 仄
   (1,5) 出韵 下平八庚 -> 下平十一尤
```

每条违规都带 `line / col / rule / actual / expected` 五字段，可直接定位。

## 五·补 创作现场演示：一首七绝从查字到定稿

**技能不替你写诗**，它给骨架、韵、规则和自检，落笔的是你。下面是刚才真实跑通的一轮。

**第 1 步·查字定韵**（不要先凑平仄）：

```
python scripts/check.py char 秋 --book pingshui
→ 秋：平，下平十一尤
python scripts/check.py char 客 --book pingshui
→ 客：仄，入声十一陌      ← 现代读平声，古属入声，最大风险点
python scripts/check.py char 梦 --book pingshui
→ 梦：仄、平两读          ← 多读字要按句意定
```

选定韵脚「下平十一尤」：秋、愁、楼、留。

**第 2 步·按八步流程落笔**（立意→择境→定韵→布句→章法→炼字），先写一稿：

> 一夜西风满画楼，寒灯照客不成眠。故园此夜应无恙，只剩秋声伴夜长。

**第 3 步·机检，抓出两个问题**：

```
(1,7) 出韵  下平十一尤 -> 下平一先
(3,4) 同字复用，宜斟酌  夜
```

一稿里「眠/长」根本不在尤韵，且「夜」重复两次。

**第 4 步·按提示改**（统一韵脚、删重复字）：

> 西风一夜上高楼，冷雨孤窗客自愁。梦绕江南烟水路，满江秋色伴君留。

```
verdict=pass, hard=0, 但还有一条 soft：(4,2) 同字复用「江」
```

**第 5 步·再改 soft 提示**：

> 西风一夜上高楼，冷雨孤窗客自愁。梦绕江南烟水路，满襟秋色伴君留。

```
verdict=pass, hard=0, soft=0, EXIT=0
yijing.py scan → no_risks_detected, 风险=0
```

**这轮演示说明了三件事**：

1. 机检抓的是**形式**（出韵、重字），抓不了「写成什么样」——立意和句子还得你自己想
2. soft 提示不会判你错，只是「宜斟酌」——改不改由你定；我这里选择改，是为了示范闭环
3. `char` 查字必须走在落笔之前——「客」是入声、「梦」有两读，凭现代口猜必然出错

## 六、三个必须知道的边界

1. **判不了就说判不了**。韵表未收录的字、双源冲突的词牌，返回
   `insufficient_data` / `conflict`（EXIT=3），**不会判成「出律」**。

2. **对仗分三层**。L1 字数与平仄硬判；L2 句法结构 `not_supported`；
   L3 依内置出处词典给工对/邻对/宽对/借对/合掌/unable 的软证据，带覆盖率。
   **永远不会输出「对仗已通过」**。

3. **词牌有三个等级**：
   - 一等谱（龙榆生/王力双源）：完整校验
   - 推定谱 1884 条：`confidence.level: provisional`，**韵脚平仄硬判、非韵脚 soft**
   - 骨架级 `skeleton_only`（钦定词谱）：只有字数/句数/韵式，`cipai` 查询返回 EXIT=3，
     `ci` 直接拒绝——**不得拿骨架当平仄谱套用**

另外：意境扫描**不判「合格/不合格」**，未检出风险 ≠ 意境合格。
