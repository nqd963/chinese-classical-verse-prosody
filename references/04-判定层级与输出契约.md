# 判定层级、输出契约与措辞

## 一、四类结论，不得互相冒充

| 结论 | 含义 | 退出码 |
|---|---|---|
| `pass` | 全部**可判定**维度通过 | 0 |
| `violations` | 存在硬错 | 1 |
| `error` | 参数非法、数据缺失、环境不满足 | 2 |
| `no_data` / `conflict` / `insufficient_data` | 判不了：词牌未收录 / 双源冲突未裁定 / 韵表未收该字 | 3 |

「判不了」与「判错了」必须分开。把缺字判成出律是**误伤用户**；把冲突词牌判成通过是**放过违规**。两者优先级相同：都不许发生。

## 二、违规项的五个恒存字段

每条 `violation` 恒含：`line` `col` `rule` `actual` `expected`。另附：

- `code` —— 固定码表（`V-TONE` `V-GUPING` `V-SANZE` `V-SANZE-SOFT` `V-SANPING` `V-RHYME` `V-RHYME-DUP` `V-NIE` `V-NIAN` `V-CHARS` `V-SEED` `V-NEIGHBOR` `V-RHYME-SHIFT` `V-REPEAT` `V-OPT` `V-NODATA` `V-TEAO` `V-ZHEYAO` `V-AOJIU` `V-AOJIU_UNRESCUED`），模型不得自造码；
- `severity` —— `hard` 参与合律判定，`soft` 只作提示；
- `rule_ref` —— 规则出处（裁决书条号 / 需求编号 / 数据文件）；
- `evidence` —— 定位依据：骨架、谱行、该字全部读法、偏离位置、拗救定位等；
- `expected_set` / `candidates` —— 允许集合与同部候选字。

**soft 码不参与「合律」判定**。输出里若把 soft 说成「出律」，属措辞违规。

## 三、三条固定的措辞约束

1. **对仗**：只能说「L1 字数与平仄硬判；L2 句法未做；L3 依内置出处词典给软性证据，未覆盖标 unable」。禁止说「对仗工整」「对仗已通过」。L3 输出必须带 `coverage`（可判位置/总字数）与「非定论」标签。
2. **模型判断**：凡由模型给的艺术判断（词性、意义类别、工拙、意境），必须标注「模型判断，非机器校验」，且在版式上与机器结论可区分。
3. **等级**：`confidence.level = first` 才可称「已校验」；`second` 只能说「人工参照，未裁定」。

## 四、拗救的定位说明

差集式必须能说清「哪一字拗、哪一字救」：

| 式 | 拗 | 救 | 说明 |
|---|---|---|---|
| `仄平平仄平` | 第 1 字 | 第 3 字 | 一拗三救 |
| `平仄仄平平仄平` | 第 3 字 | 第 5 字 | 三拗五救 |
| `仄仄仄平平仄平` | 第 3 字 | 第 5 字 | 三拗五救 |

给不出定位说明的式即为非法多余式（selftest 会 fail）。**不设具名拗救白名单**——白名单会漂移、会漏配。

孤平的 `evidence` 措辞固定为：

```json
{"骨架": "平平仄仄平",
 "触发条件": "第 1 字与第 3 字不得同时为仄（实为 1=仄、3=仄）",
 "等价修法": "第 1 字改平，或第 3 字改平"}
```

## 五、数据可信声明

每次输出带 `data_source.files`，值为该数据文件的 `sha256` 前 12 位。用户可据此确认判定依据的版本。

数据文件本身带 `source`：书名、版本、公版状态、`sha256`、抽取时间、实测统计。凡写数字必须写口径（例如「208 标题数 = 145 词牌头 + 63 体式头」），口径混用即判错。

## 六、幂等与可复现

- 同一输入两次执行，输出**逐字节一致**：所有 JSON 用 `sort_keys` + `ensure_ascii=False` + 固定缩进 + 固定换行；
- 不含时间戳、不含随机序、不含机器相关信息（无绝对路径、无盘符）；
- 夹具与回归的随机抽样用固定种子（`20261120`），换机器结果不变。

## 七、错误码与提示语

| 码 | 用户该怎么看 |
|---|---|
| `V-TONE` | 该字平仄与骨架不符；看 `evidence.该字平水韵读法` 是否有多读可选 |
| `V-GUPING` | 孤平；按 `evidence.等价修法` 改任一位即可 |
| `V-SANZE`（落调，hard） | 三仄尾且上二／上三字不同平（五言第 1、3 同仄 / 七言第 3、5 同仄）；按 `evidence.配对位` 改配上位为平 |
| `V-SANZE-SOFT`（合法三仄尾，soft） | 下有三仄、上必二平成立，仅提示不判错 |
| `V-SANPING`（hard） | 三平尾，无条件禁；改末三字第 1 或第 2 字 |
| `V-NIE` / `V-NIAN` | 整句粘对关系错，不是单字问题；先看 `evidence.偏离位置` |
| `V-RHYME` | 出韵；`candidates` 给了同部可选字 |
| `V-RHYME-DUP` | 重韵；换掉后出现的那一个字 |
| `V-NODATA` | **不是你的错**：韵表没收这个字，该位判不了 |
| `V-TEAO` | 特拗变体，通行写法，一般不须改 |
| `V-OPT` | 用了衬字位，合规，仅备忘 |
