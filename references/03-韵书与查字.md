# 韵书与查字

## 一、三部韵书的分工

| 韵书 | 规模 | 用途 | 不能用来做什么 |
|---|---|---|---|
| 平水韵 | 106 韵目 / 4281 字 | 近体诗平仄与押韵 | 判词韵 |
| 词林正韵 | 19 部 / 115 小韵组 / 5018 字 | 词平仄与押韵 | 判诗韵 |
| 邻韵通押表 | 15 类 + 8 入声类 | 邻韵（兼容模式） | 严格模式不得启用 |

**三者不可混用。** 混用产生的错误是系统性的，且往往表现为「全都差一点」，极难靠人眼发现。

## 二、平水韵的抽取要点

源文件把同一大类的全部韵字排在**一整行**里（最长一行 1363 字），不可能按行切。切分靠「韵目名」前瞻匹配：`一东二冬三江…` 依次出现，按 `数字＋韵目名＋`，`` 定位边界。

实测结果：`上平15 / 下平15 / 上29 / 去30 / 入17 = 106` 韵目，去重 4281 字；全表非 CJK 字符 0 处。

### 去声四寘的污染字已剔除

源文件四寘末尾串入 `二近始术瑟德`：`术/瑟/德` 属入声、`始` 仅上声、`近` 不属四寘。这 5 字**从四寘剔除**并登记 `suspect_queue.json`，不是「登记后保留」。

理由不在「字会不会丢」，而在多读语义：校验器的多读判定是「任一所取读音成立即通过」。若「术」同时在四寘与四质，用「术」押四寘的作品会被判合韵——**放过一个本应判错的违规**。剔除只会造成可被用户当场质疑的误报。两害相权：宁可误报，不可放过。

通则：凡疑似转录污染导致的字-韵部挂接，一律不进判定表，进 `suspect_queue.json` 待裁定。

## 三、词林正韵的 header 污染（本项目最危险的假阴性）

源文件有 13 行在组体末尾同接 `仄声：上声…去声…通用`，例如：

```
【十灰<半>】灰恢魁…莓仄声：上声四纸五尾八荠十贿<半>　去声四寘五未八霁…
```

按「一行＝一个小韵组」切，`上声四纸…通用` 里的单字会进字表。真正致命的是**「去」「声」被登记为十灰（平声）韵字**：含「去」的句子平仄全错，用「声」作灰韵韵脚会被判押韵通过——这是**静默放行**，比误报危险得多。

实现的硬断言（`datacheck.check_cilin`）：

1. 切分前先截断组体：遇 `平声：`/`仄声：`/`入声：` 标签即行内截断，标签之后只用于解析「通用」关系，不进字表；
2. 任何组的字串不得含 header 词组 `平声/仄声/入声/通用/独用/<半>`；
3. 组字数上界：`十灰<半>` 平声组 ≤65（实测 39+27 两组）、对应仄声组 ≤45（实测 14/20/29/3）；
4. 专项：「去/声/上/入」不得被登记为灰/佳/齐的平声韵字。

注意 A9 原有的三条断言（19 部齐备 / 14+5 结构 / 抽 20 条带注字）**全都会通过，而数据已经带病**。断言全绿而数据带病，是最坏的一种「通过」。

## 四、繁简归一

平水韵表本体是**简体**，韵表不得掺繁体。但用户的诗可能与王力举例一样写繁体（王力原文 `無` 出现 122 次、`雲` 119 次），故查询层必须做繁→简归一。

- `data/trad_simp.json`：`t2s`（繁→简，410 条有效）＋ `alias`（异体，23 条，如 沉→沈、樽→尊）＋ `t2s_ineffective`（诊断用）；
- 硬断言：`pingshui 键集 ∩ t2s 键集 = ∅`、`∩ alias 键集 = ∅` —— 防止有人往韵表里补繁体；
- 回归报告单列**繁简归一命中数**（实测 141 次），失败归因于数据链而非韵表错。

## 五、多读字怎么取

同一个字可能兼平仄（如「看」平/去、「怨」平/去、「为」平/去）。取法不能逐字贪心：

- **按句统一分配**：先试「全句都满足骨架」，再试「全句都满足特拗形态」，都不成立才逐字取最优；
- 逐字贪心会为了凑骨架而给某个字取错读法，把真正的拗句误判成平仄错位。

实测教训：`情人怨遥夜` 的「怨」若逐字取平，全句变成 `平平平平仄`，第 4 字随即报错；改成按句分配后正确识别为特拗 `平平仄平仄`。

## 六、半部韵只对三个韵目成立

《词林正韵》的 `<半>` 标记共 36 处、9 组半韵。但**字级拆分只对 元/阮/愿 三目成立**：

- 十三元 / 十三阮 / 十四愿：剥离括号注后集合交集为 **0** → 可拆；
- 九佳（佳、涯）、九泰（外）、十卦、十一队、十贿、十灰：存在 1–2 字真共现 → 是**重叠归属而非划分**，不可拆。

故 `linvun.json` 里 `half_resolution` 默认 `coarse`（整部），仅「去声十四愿」为 `fine`。改这一项即可切「整部宽松」口径，**改配置不改代码**。

依据须在数据文件与文档中明示：「半部字级划分依据《词林正韵》`<半>` 标记」，不得让读者误以为出自平水韵或王力原表。

## 七、邻韵

传统邻韵归并为 15 类（东冬／江阳／支微齐／鱼虞／佳灰／真文元寒删先／萧肴豪／庚青蒸／覃盐咸等）＋ 8 个入声类。严格模式默认**不认**邻韵；兼容模式仅首句可借（孤雁出群格）。

不得用「韵目排列相邻」代替传统归类——那在「三江↔七阳」等处会直接失效。
